# Sollene: Creative Hero with Liquid Background

A free prompt by **Layer Web**. Paste it into your AI tool and get a full-screen animated hero section in a single `index.html` file, with no framework and no build step.

## How to use

1. Open `sollene.md` and copy all of its content.
2. Paste it as one message into Claude Code, Cursor, Lovable or V0.
3. Open the generated `index.html` in your browser.
4. Swap in your own text, colours and image, and keep the structure.

Tip: adjust one section at a time. Asking for a full rewrite can overwrite the parts you already fixed.

## What's inside

- A full-screen hero section with a liquid background effect that reacts to the cursor
- Animated entrance, responsive layout and accessibility basics
- Exact measurements, colours and animation timings, so the result matches the original
